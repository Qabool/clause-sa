## Short description
Statistical assessment of calibration data with method validation, uncertainty and reports.

## Description
CLAUSE Statistical Assessment helps calibration and testing professionals analyse measurement data with confidence. Enter or import your data, let the app check that the method suits it, and get results with expanded uncertainty, graphs and a complete, printable report.

**What you can do**
- Estimate a quantity from logged data with method validation (including ISO 28037 straight-line models)
- Regression and ANOVA analysis
- Repeatability, temporal, spatial and homogeneity studies, with distribution and outlier checks
- See results with combined and expanded uncertainty, coverage intervals and domain checks
- Print or export reports as PDF (Pro: Excel workbooks)
- Keep every report in a searchable repository with Draft and Completed states
- Make an editable copy of a completed report without changing the original
- Recycle bin keeps deleted reports for 30 days; export and restore full backups

**Your data stays with you.** Your account and reports are stored on your own device. There is no advertising and no tracking.

**Free and Pro**
- Free: works online; each week (Monday to Sunday) up to 10 reports computed and 5 completed; unlimited drafts up to method validation.
- Pro (subscription): no weekly limits, offline use, Excel export.

CLAUSE supports your own quality work; you remain responsible for checking results. It does not make a laboratory or report accredited or compliant with any standard.

## Notes for certification (paste into the submission)
No test account is needed. On first launch the app asks you to create a local account: enter any User ID (for example `reviewer`), your name, a password with a letter and a number (for example `Review2026`), and answer three security questions. There is no email verification; all data stays on the device.

To see the main features: Configuration -> Variable Configuration -> create two variables (choose any unit group). Then Statistical Assessment -> Estimator -> select the two variables, enter 12 rows of data, set a target value, choose a method and continue to Computation. "Save & close" completes the report; it then appears under Report Repository.

The Free plan is online-only by design: if you test with the network off, a screen reading "Internet connection required" appears. Subscriptions are sold as add-ons with Product IDs `clause_pro_monthly` and `clause_pro_yearly` using the Digital Goods API and the Payment Request API. The app does not show advertising and does not collect data.
